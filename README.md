# Out of Focus? The rise, fall and comeback of the digital camera

FIT3179 Data Visualisation 2 by Jayden De Kauwe, October 2026 | 34976566

**Live page:** https://jdk007.github.io/Camera_Collections/

## Repository layout

- `index.html`: the page (text, layout and chart containers)
- `css/style.css`: page styling
- `js/charts.js`: loads each chart with vega-embed
- `specs/`: one Vega-Lite JSON specification per chart and map (12 in total)
- `data/`: the data files the charts read (CIPA, 1000 Cameras Dataset, UN Comtrade, World Bank, ABS, Natural Earth map outlines). The `comtrade_au_camera_imports_20XX.json` files are the original Comtrade downloads, kept for reference.

All data sources and links are listed in the page footer.
